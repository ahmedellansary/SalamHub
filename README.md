## 🌟 Key Features

- **Personalized Onboarding Pathways**: Tailors content and initial inquiry tracks based on user perspective (Atheist/Agnostic, Christian, Jewish, or Curious).
- **Comprehensive Debate Arena**: Categorized, searchable, and paginated archive of real-world theological debates and dialogues with 1-click cinema modal playback.
- **Evidence-Based Myth Busters**: Clear refutations of misconceptions categorized by topic (History, Science, Women, Prophethood, and more).
- **Dynamic Multilingual Architecture**: Fully supports 8 languages with seamless bidirectional (LTR / RTL) layout switching:
  - English (`en`)
  - العربية (`ar` - RTL)
  - Français (`fr`)
  - Español (`es`)
  - Türkçe (`tr`)
  - Deutsch (`de`)
  - Bahasa Indonesia (`id`)
  - اردو (`ur` - RTL)
- **Dual-Accent Design System**: Instant color palette toggle between **Neon Teal** and **Bridge Gold** powered by CSS custom properties and persistent client-side storage.
- **Responsive & Accessible**: Mobile-first design, smooth transitions, fluid typography, and zero third-party framework dependencies.

---

## 🛠️ Architecture & Tech Stack

- **Markup**: Semantic HTML5 with accessibility ARIA standards.
- **Styling**: Modular CSS3 utilizing custom design tokens, backdrop filters, CSS Grid, and Flexbox.
- **Logic**: Vanilla ES6+ JavaScript featuring client-side state management, DOM rendering engine, and zero external runtime dependencies.
- **Hosting**: GitHub Pages (CDN-backed, instant worldwide delivery).

## 🚀 Getting Started

No build process or npm installation is required.

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/ahmedellansary/SalamHub.git
   ```
2. Open `index.html` directly in your browser or run a lightweight local static server:
   ```bash
   npx serve .
   # or
   python -m http.server 8000
   ```
